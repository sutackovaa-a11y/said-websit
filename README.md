# SAID — образовательная платформа по изучению таджвида

SAID — образовательный сайт для изучения арабского алфавита, махраджей букв и правил таджвида. Платформа предназначена для начинающих и помогает закреплять знания с помощью наглядных материалов и практических упражнений.

## Возможности проекта

- Главная страница с навигацией по разделам.
- Изучение арабских букв и мест образования звуков (махраджей).
- Обучающие материалы по правилам таджвида.
- Раздел интерактивных упражнений для закрепления знаний.
- Видеоматериалы обучающего канала «Арабия».
- Раздел отслеживания прогресса обучения.
- Адаптивный дизайн для разных размеров экрана.

## Разделы сайта

- Главная
- О таджвиде
- Уроки
- Буквы
- Правила
- Упражнения
- Видео
- Контакты

## Технологии

- HTML5
- CSS3
- JavaScript

## Дизайн

В дизайне используются кремовые, сиреневые и фиолетовые оттенки, декоративные элементы в исламском стиле, карточки разделов и иллюстрации.

## Запуск проекта

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите `index.html` в браузере.

Для удобной разработки можно открыть проект в Visual Studio Code и использовать расширение Live Server.
